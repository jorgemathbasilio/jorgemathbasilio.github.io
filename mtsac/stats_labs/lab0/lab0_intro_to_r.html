# § 0. Intro to R We use computers for all sorts of everyday tasks. I feel it is time that a computer becomes an important tool in studying mathematics and statistics. This opens up a lot of interesting possibilities for the types of problems one can solve. ## What is R? `R` is a powerful, comprehensive, open-source software framework for doing professional statistics. It is possible to download and install the software on computers, or to use it through a website-interface without downloading anything. We will use `R` through a website-interface in the form of a "Sage Worksheet". In fact, what you are reading here is a Sage Worksheet which has the ".sagews" file extension. This is an interactive document that will guide you through the first steps of getting familiar with R. ## Why use R? - It's free! - Using it on web is free via CoCalc - Downloading it is free (if you want to use it without internet) - It's open source! - No hidden algorithms (you can look at source code if you wish--and look "under the hood" so to speak) - Lots of resources to get help (use google to search) - **It will prepare you for the future!** - You will likely need to learn some basic programming no matter what you study in college - In Pyschology, for example, it's common to learn R (or Python) when learning statistics - Data Analyst: hot new field where there's lots of jobs! - It truly and honestly answers the question student's always ask: "When will I ever use this???" - Bragging rights: put this on your resume! Tell employers when interviewing to stand out from the crowd ## Why not just use graphing calculators? Graphing calculators are still rather popular. I used one in high school in the 1990s. Let's say we would like to study and work with a large data set. Using software, like `R`, I can upload a file with the data into a folder for the project, and distribute it to all students with a click. By comparison, with a graphing calculator, the data would have to be entered by each student...by hand. We do this in class because we need to take exams but for "real world" data sets, the number of entries are huge! Students can take the images and outputs of their computations in `R` and easily add them to any document for professional-looking reports, or undergraduate research papers suitable for publication. A picture on a graphing calculator is idle and immovable. Finally, **you will be learning a skill** and it will take time to get comfortable with it.

# Quick Comment about 'Comments' Comments are very useful in programming and coding. They are parts of code that are NOT read or implemented by the program but are there to be helpful for humans--that is, for you or me to read :-) In R, any text after a hashtag is not read by the program for that line. # § 3. Variables and Assignment in R Variables in a programming language are different than our usual math notation. Typically, when you just do the line above *nothing happens*. There's no output! This is because we've only *assigned* the value of 3 to the variable `x` and stored it to memory.
